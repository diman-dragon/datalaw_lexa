# Changelog

Версия растёт на единицу в последнем знаке с каждой итерацией (`npm run bump`).

## 0.0.1
- Проект `datalaw_lexa`, пакет `app.datalaw.lexa`.
- Полностью офлайн: словарь собирается из Wiktionary (kaikki.org), wordfreq и Tatoeba и вшивается в APK.
- Англо-русский словарь: значения, перевод по значениям, тезаурус, примеры, обратный поиск RU→EN, озвучка системным TTS.
- Интерфейс RU/EN; темы «светло-коричневая» и AMOLED; настройки — отдельный экран.
- Постоянный публичный ключ подписи: обновления ставятся поверх.
