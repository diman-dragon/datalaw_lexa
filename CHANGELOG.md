# Changelog

Версия растёт на единицу в последнем знаке с каждой итерацией (`python3 scripts/bump_version.py`).

## 0.1.4 — уборка
- Убрана вкладка выгрузки слов: нижняя панель снова из 4 вкладок, вместе с ней удалены связанный код, строки, настройки, зависимости и тесты.
- История: запись «d MMMM» из разных лет давала одинаковый ключ списка и роняла экран — в подписи добавлен год для прошлых лет.
- Подсказки при вводе: для коротких префиксов («a», «th») просматривались только первые 600 слов по алфавиту и частотные слова в выдачу не попадали — теперь просматривается весь диапазон.
- Сборщик данных: символ «÷» больше не считается буквой в ключах и токенах; поправлены устаревшие комментарии (пути, способ загрузки). `.editorconfig`: для Kotlin — 4 пробела.

## 0.1.2 — ровные подписи
- Новый компонент [`FitText`](app/src/main/kotlin/app/datalaw/lexa/ui/components/FitText.kt): подпись всегда в одну строку, слово не переносится и не обрезается, при нехватке места кегль плавно уменьшается.
- Нижняя панель: все подписи на общем кегле (`FitGroup`) — «Настройки», «Мои слова» стоят ровно, без переносов и многоточий; активная вкладка — полужирным.
- `FitText` подключён к кнопкам (`PrimaryButton`, `GhostButton`, `LinkButton`), чипам, переключателям, заголовку экрана, `SectionTitle` и `Eyebrow`; у кнопок уменьшены боковые поля, чтобы подписи помещались крупнее.

## 0.1.0 — полностью на Kotlin
- **Приложение переписано с Capacitor/Preact/TypeScript на нативный Kotlin + Jetpack Compose.** Те же экраны (Поиск, Слово со вкладками «Значения / Перевод / Синонимы / Примеры», обратный поиск RU→EN, «Мои слова», История, Настройки из 5 подэкранов), та же палитра «Какао» / AMOLED, тот же формат словаря и тот же постоянный ключ подписи — версия ставится поверх прежней.
- Озвучка (`TextToSpeech`) и голосовой ввод (`SpeechRecognizer`) — теперь обычный Kotlin-код без мостов Capacitor. Разрешение микрофона запрашивается системным диалогом.
- «Мои слова», история и настройки переносятся из прежней версии автоматически (читаются из её хранилища при первом запуске).
- Словарь по-прежнему читается «на лету» с ветки `dictionary` и кэшируется; «Скачать для офлайна» — на корутинах (6 параллельных загрузок, докачка, повторы, отмена).
- Сборка — Gradle (`gradle :app:assembleRelease`), CI обновлён; скрипты веб-версии (`android-patch.mjs`, `release-apk.sh`, плагины на Java) удалены.
- Сборщик словаря `scripts/build_data.py` (Python) не менялся: он нужен только CI и выдаёт те же файлы.

## 0.0.5
- **Голосовой ввод слов.** Кнопка микрофона в строке поиска открывает окно-шторку: «дышащая» кнопка, кольца и столбики реагируют на громкость голоса, распознанное слово появляется по мере произнесения. Переключатель English / Русский (выбор запоминается). Если слово есть в словаре — открывается сразу, иначе подставляется в строку поиска с подсказками; из вариантов распознавания выбирается тот, что есть в словаре.
- Android: нативный плагин `LexaVoice` (`android.speech.SpeechRecognizer`, офлайн-пакет предпочтителен), разрешение `RECORD_AUDIO`, `<queries>` для службы распознавания (`scripts/android-patch.mjs`). В браузере — Web Speech API. Системная «Назад» закрывает окно.
- Исправлено: пустой список примеров запоминался на сессию, если сети не было в момент запроса (теперь — сообщение и «Повторить»); сбой `initNative()` больше не оставляет вечную заставку; `TextEncoder` в хэше создаётся один раз.
- Политика конфиденциальности в «О приложении» упоминает системное распознавание речи; README приведён в соответствие (версия, онлайн-режим словаря).

## 0.0.4
- Экраны по образцу Forma: нижняя навигация из 4 вкладок (Поиск · Мои слова · История · Настройки), свайп влево/вправо между вкладками.
- Настройки — вкладка с 5 подэкранами со свайпом (Вид · Язык · Данные · Источники · О нас), полоса вкладок и точки; элементы в карточках-группах; «О нас» — в рамке с уголками, знаком D и подписью DataLaw DesignLab.
- Проверка английского/русского голоса в настройках и подсказка, где установить голоса.
- Системная кнопка «Назад»: слово → предыдущий экран; другая вкладка → главная; на главной — выход из приложения.

## 0.0.3
- Единое оформление DataLaw DesignLab (как в Forma): палитра AMOLED / светло-коричневая, системный шрифт + серифные заголовки, навигация, кнопки, радиусы; убран шрифт Inter.
- Новая иконка: фирменная «D» DataLaw + раскрытая книга (слой для тематических иконок Android 13+, заставка, иконка Google Play). Знак «D» в интерфейсе и на экране «О приложении» с подписью DataLaw DesignLab.
- Озвучка: исправлено «синтез речи не установлен». Причины — Android 11+ скрывал движки TTS без `<queries>` в манифесте и голоса WebView грузились асинхронно. Теперь нативный плагин LexaSpeech (android.speech.tts.TextToSpeech) с запасным Web Speech; отдельные сообщения: нет голоса языка / нет движка / сбой.
- `scripts/android-patch.mjs` донастраивает проект android/ (плагин, манифест).
