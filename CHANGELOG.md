# Changelog

Версия растёт на единицу в последнем знаке с каждой итерацией (`npm run bump`).

## 0.0.3
- Единое оформление DataLaw DesignLab (как в Forma): палитра AMOLED / светло-коричневая, системный шрифт + серифные заголовки, навигация, кнопки, радиусы; убран шрифт Inter.
- Новая иконка: фирменная «D» DataLaw + раскрытая книга (слой для тематических иконок Android 13+, заставка, иконка Google Play). Знак «D» в интерфейсе и на экране «О приложении» с подписью DataLaw DesignLab.
- Озвучка: исправлено «синтез речи не установлен». Причины — Android 11+ скрывал движки TTS без `<queries>` в манифесте и голоса WebView грузились асинхронно. Теперь нативный плагин LexaSpeech (android.speech.tts.TextToSpeech) с запасным Web Speech; отдельные сообщения: нет голоса языка / нет движка / сбой.
- `scripts/android-patch.mjs` донастраивает проект android/ (плагин, манифест).

## 0.0.2
- Словарь больше не вшит в APK: по умолчанию приложение работает онлайн (файлы из ветки `dictionary` репозитория, читаются «на лету» и кэшируются).
- Настройки → «Данные словаря»: кнопка «Скачать для работы офлайн» (прогресс, отмена, докачка), обновление, удаление, очистка кэша.
- Подсказка на главном экране про офлайн; понятные ошибки при отсутствии сети.
- CI: job `data` публикует словарь в ветку `dictionary` (раздаётся через raw.githubusercontent.com, Pages не нужен); APK собирается без данных.

## 0.0.1
- Проект `datalaw_lexa`, пакет `app.datalaw.lexa`.
- Полностью офлайн: словарь собирается из Wiktionary (kaikki.org), wordfreq и Tatoeba и вшивается в APK.
- Англо-русский словарь: значения, перевод по значениям, тезаурус, примеры, обратный поиск RU→EN, озвучка системным TTS.
- Интерфейс RU/EN; темы «светло-коричневая» и AMOLED; настройки — отдельный экран.
- Постоянный публичный ключ подписи: обновления ставятся поверх.
