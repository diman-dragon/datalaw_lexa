# datalaw_lexa — англо-русский словарь для Android (онлайн + офлайн по кнопке)

Capacitor 8 · Preact · TypeScript · Vite. Версия **0.0.1** (дальше +1 в последнем знаке: `npm run bump`).

Весь словарь вшит в приложение — интернет не нужен.

> Oxford и Cambridge — проприетарные, встроить их в приложение нельзя. Данные собираются из открытых источников.

## Как работают данные
Словарь собирается в CI и публикуется в ветку `dictionary` репозитория; приложение читает файлы оттуда «на лету» (с кэшем). В **Настройки → Данные словаря** — кнопка «Скачать для работы офлайн»: весь словарь сохраняется на устройстве.

**Хостинг словаря — бесплатно и без настроек.** Job `data` публикует собранный словарь в ветку `dictionary` этого репозитория, а приложение читает файлы с `https://raw.githubusercontent.com/<owner>/<repo>/dictionary/`. Нужно только, чтобы репозиторий был **публичным** (Settings → General → Danger Zone → Change visibility; ключ подписи и так публичный). GitHub Pages не нужен. Адрес можно переопределить через `VITE_DATA_URL`.

В dev-режиме (`npm run data:sample && npm run dev`) данные берутся из `public/data` локально.

## Данные

`scripts/build_data.py` собирает словарь и кладёт его в `public/data` (шардированный JSON, читается через `fetch` из ресурсов APK):

| Что | Источник | Лицензия |
| --- | --- | --- |
| Значения, части речи, IPA, примеры, синонимы/антонимы/гиперонимы/гипонимы, этимология, **переводы на русский по значениям** | Викисловарь через [kaikki.org](https://kaikki.org) (Wiktextract) | CC BY-SA |
| Частотность, отбор слов, ранжирование подсказок | [wordfreq](https://pypi.org/project/wordfreq/) | CC BY-SA |
| Предложения EN↔RU для примеров | [Tatoeba](https://tatoeba.org) | CC BY 2.0 FR |
| Озвучка | системный синтезатор речи Android (офлайн-голоса) | — |

Что получается: до ~90 000 английских слов (частотные + имеющие русский перевод), словоформы-перенаправления (`ran → run`), обратный индекс **RU→EN**, подсказки при вводе на обоих языках, исправление опечаток.

```bash
npm run data:sample   # крошечный образец (10 слов) — мгновенно, для разработки
npm run data:build    # полная сборка: pip install wordfreq; качает ~3 ГБ, 15–40 мин
```

Размер и состав настраиваются: `python3 scripts/build_data.py --download --max-words 120000 --min-zipf 2.5`. Адреса дампов — константы в начале скрипта (`KAIKKI_URLS`, `TATOEBA_*`), можно передать свои: `--kaikki-url`, `--kaikki файл.jsonl.gz`.

## Подпись: обновление поверх установленного

Android ставит APK «поверх» только если **подпись та же** и `versionCode` больше. Поэтому:

- ключ `signing/datalaw_lexa.keystore` **лежит в репозитории** (публичный; алиас `datalaw_lexa`, пароль `datalaw_lexa`) — CI и локальные сборки подписаны одним и тем же ключом;
- в CI `versionCode` = номер запуска workflow и растёт сам; локально задайте `VERSION_CODE=<больше установленного>`;
- SHA-256 сертификата: `02:1D:DE:CE:68:8E:FE:67:16:7F:83:9F:50:63:7C:5D:56:0E:99:9C:08:3E:62:62:EB:64:EF:C7:CB:B7:59:E2`.

⚠️ Ключ публичный — любой может подписать APK тем же ключом. Для личной установки и открытого проекта это нормально, для Google Play — нет (там нужен приватный ключ). Не меняйте и не пересоздавайте ключ: иначе обновление поверх станет невозможным.

## Быстрый старт

Node 22+, Python 3.10+ (+ `pip install pillow` для иконок), JDK 21, Android SDK.

```bash
npm install
npm run data:sample      # или data:build
npm run check            # типы + TS-тесты + тесты пайплайна данных
npm run dev              # http://localhost:5173
npm run android:release  # → release/datalaw_lexa-0.0.1.apk (подписанный)
npm run android:open     # открыть в Android Studio
```

В VS Code: **Run Task** → `dev`, `check`, `android: …`; **F5** — отладка в Chrome.

## GitHub Actions

`.github/workflows/android.yml`: `check` (типы, тесты; единственное, что идёт на pull request) → `data` (сборка словаря, кэшируется по хэшу скрипта) → `android` (подписанный APK-артефакт `datalaw_lexa-apk`; по тегу `v*` — ещё и GitHub Release). Для публикации релиза включите *Settings → Actions → Workflow permissions → Read and write*. Рекомендуется закоммитить `package-lock.json` и папку `android/` (`npm run cap:add`).

## Интерфейс

- Поиск EN и RU с подсказками, слово дня, история, «Мои слова»
- Карточка слова: значения, перевод по значениям, тезаурус, примеры (словарь + Tatoeba), IPA US/UK, частотность
- **Настройки — отдельный экран** (шестерёнка на главной): тема (Авто / Светло-коричневая / AMOLED), язык интерфейса RU/EN, акцент, вибро, сведения о данных
- Строки интерфейса — `src/i18n.ts`

## Ограничения

- Пайплайн данных проверен на образце формата kaikki; реальные дампы из этой среды скачать не удалось — при первой полной сборке проверьте адреса и логи.
- Слова без русского перевода в Викисловаре показываются без него (машинного перевода офлайн нет).
- Предложения Tatoeba привязываются к однословным ключам; фразы («ice cream») примеров-предложений не получают.
- Озвучке нужны установленные в системе голоса.
