# datalaw_lexa — англо-русский словарь для Android (Kotlin)

Нативное приложение: **Kotlin · Jetpack Compose · Material 3**. Версия **0.1.0** (прежняя веб-версия на Capacitor/Preact заменена; данные, подпись и `applicationId` те же, поэтому ставится поверх).

Словарь работает онлайн (файлы читаются «на лету» и кэшируются), а после загрузки в настройках — полностью офлайн.

> Oxford и Cambridge — проприетарные, встроить их нельзя. Данные собираются из открытых источников.

## Вкладка «Карточки» — список слов → колода для DL Studio

Загрузите список слов, введите их вручную или попросите **N самых частотных слов** (100 / 300 / 600 / 1000) — приложение переведёт их из словаря и выдаст файл, который импортируется в DL Studio (Библиотека → импорт, на любом уровне: проекты / проект / колода). Формат — дерево проект → колода → карточки:

```json
{
  "name": "Английский",
  "items": [
    {
      "name": "Моя колода",
      "items": [
        {
          "name": "to suggest",
          "back": "предлагать, намекать",
          "hint": "/səˈdʒɛst/ · глагол\nTo put forward an idea",
          "explanation": "Она предложила сходить поужинать.",
          "example": "She suggested going out for dinner."
        }
      ]
    }
  ]
}
```

Как поля показываются в DL Studio: `name` — слово на лицевой стороне (озвучивается), `back` — перевод на обороте, `hint` — подсказка по лампочке на лицевой стороне (транскрипция · часть речи, со второй строки короткое английское определение — без перевода, чтобы не выдавать ответ), `explanation` — пояснение под переводом (здесь — перевод примера), `example` — английский пример с динамиком. Пустые поля в файл не пишутся.

- **Ввод.** Поле (одно слово или фраза; несколько — с новой строки или через `;`) и кнопка «Загрузить список»: `.txt` (по слову в строке, нумерация/маркеры и `#`-комментарии игнорируются), `.csv`/`.tsv` (первая колонка, заголовок пропускается), `.json` (массив строк/объектов с `front`/`word`/`name` либо сама колода DL Studio — берутся слова карточек).
- **Частотные слова.** Блок «Самые частотные слова»: из индекса словаря берутся слова с наибольшей оценкой Zipf (wordfreq), без форм («ran»), имён собственных, сокращений и слов без русского перевода; список сразу переводится.
- **Перевод.** `back` — до 1–4 переводов (по одному из каждого значения, без повторов; настраивается). Глагол без «to» получает «to», если все его значения глагольные («suggest» → «to suggest»; для «run» — нет; выключается переключателем). Форма слова («ran») переводится по лемме («run»). Для «to X» берутся глагольные переводы.
- **Пример.** `example` + `explanation` (перевод) — пара предложений из Tatoeba: с введённой формой слова и средней длины. «Другой пример» листает варианты. Если пары нет, берётся пример из словаря **без перевода** (карточка помечена), иначе пример пустой.
- **Нет в словаре.** Показываются исправления опечаток; для русского ввода — английские эквиваленты. Выбор подсказки заменяет слово и переводит заново. Любую карточку можно править вручную (слово, перевод, подсказка, пример, перевод примера).
- **Существующая колода.** «Существующая колода…» → выберите файл колоды DL Studio (экспорт из библиотеки): слова, которые в нём уже есть (без учёта регистра и «to», по всему файлу), пропускаются, а новые карточки **дописываются в первую колоду файла** — остальные поля и порядок ключей сохраняются.
- **Экспорт.** «Сохранить JSON-файл» (системный диалог), «Копировать», «Поделиться». В файл попадают только готовые карточки.

Переводы — из Викисловаря (через kaikki.org), примеры — Tatoeba. Машинного перевода нет: слово, которого нет в словаре или у которого в нём нет русского перевода, нужно дописать вручную. Перед изучением просмотрите карточки.

## Сборка

JDK 17, Android SDK (compileSdk 35), Gradle 8.11+.

```bash
gradle wrapper --gradle-version 8.11.1      # один раз: создаёт ./gradlew
./gradlew :app:testDebugUnitTest            # юнит-тесты (Kotlin)
python3 scripts/test_build_data.py          # тесты сборщика данных (Python)
./gradlew :app:assembleDebug                # app/build/outputs/apk/debug/
VERSION_CODE=2000 ./gradlew :app:assembleRelease
```

APK подписывается постоянным ключом из `signing/` (alias и пароль — `datalaw_lexa`, ключ публичный; не пересоздавайте его — иначе обновление поверх станет невозможным). Установка поверх требует, чтобы `versionCode` был больше установленного: в CI он равен номеру запуска workflow, локально задайте `VERSION_CODE=…` (если ставите поверх старой веб-версии, возьмите значение больше её номера запуска CI). Адрес словаря — `DATA_URL` (переменная окружения или `-PDATA_URL=…`).

Версия — `version.properties`; `python3 scripts/bump_version.py` поднимает её на 1.

## Данные

`scripts/build_data.py` (Python, запускается только в CI) собирает словарь и кладёт его в `public/data` — шардированный JSON; workflow публикует его в ветку `dictionary`, а приложение читает файлы с `https://raw.githubusercontent.com/<owner>/<repo>/dictionary/`. Репозиторий должен быть **публичным**.

| Что | Источник | Лицензия |
| --- | --- | --- |
| Значения, части речи, IPA, примеры, синонимы, этимология, **переводы на русский** | Викисловарь через [kaikki.org](https://kaikki.org) | CC BY-SA |
| Частотность, отбор слов | [wordfreq](https://pypi.org/project/wordfreq/) | CC BY-SA |
| Предложения EN↔RU | [Tatoeba](https://tatoeba.org) | CC BY 2.0 FR |

```bash
python3 scripts/build_data.py --sample     # образец из 10 слов
python3 scripts/build_data.py --download --require-wordfreq   # полная сборка (~3 ГБ, 15–40 мин)
```

Хэш шардов (FNV-1a) реализован и в Python, и в Kotlin (`core/Hash.kt`); юнит-тест сверяет значения со сборщиком.

## Устройство кода (`app/src/main/kotlin/app/datalaw/lexa`)

| Пакет | Что внутри |
| --- | --- |
| `core` | модели, разбор JSON, нормализация, поиск (префикс + опечатки), хэш шардов |
| `data` | файловое хранилище (пакет/кэш), сеть, `Dictionary`, загрузка офлайн-пакета |
| `store` | настройки, «Мои слова», история (SharedPreferences; перенос из веб-версии) |
| `platform` | озвучка (`TextToSpeech`), голосовой ввод (`SpeechRecognizer`), «поделиться» |
| `cards` | генератор карточек, разбор списков слов, JSON колоды, `CardsViewModel` |
| `ui` | тема, навигация, компоненты, экраны; строки — `ui/i18n/Str.kt` (RU/EN) |

## Что изменилось по сравнению с веб-версией

- Нет свайпа между вкладками нижней панели (переключение — нажатием); системная «Назад» работает как раньше.
- Вкладок стало 5 (добавлены «Карточки»).
- Сборщик словаря остался на Python: он нужен только CI, а `wordfreq` — Python-библиотека без аналога на JVM.
